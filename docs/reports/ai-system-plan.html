Data platform

Collects, cleans and connects everything. Already running: 22 GB, refreshed every Sunday, backed up on ARKO HDD.

built

Intelligence

Small, fast models trained on your data. Each new version must beat the current one on unseen recent data before it is used.

next

Action

An MCP server gives agents short, exact answers instead of raw data, so each question costs a few hundred tokens. People always approve what goes out.

next

Why it is cheap to run

  • Heavy work happens on your Mac, for free: collecting, cleaning, training and scoring.
  • Agents never read the data. They call a tool such as score_post or next_occasions and get a short answer back.
  • A paid AI model is used only for creative writing: captions and scripts. Routing and checking use a cheap or local model.
  • Answers are cached. The same question asked twice costs nothing the second time.

How it runs by itself

Every job is scheduled, checked and logged. If something fails, the last good version stays in use and you get an alert.

WhenWhat runs automatically
Every nightOwn posts, metrics and orders from the warehouse; YouTube searches; health checks
Every SundayMarket refresh (prices, menus, reviews, social), rebuild and test all tables, new training sets, retrain and compare models, new 15-day content plan, backup reminder
Every morningAgents prepare the day's drafts from the plan; you approve them
Every monthModel report: what each model predicted versus what really happened; drift check
On an eventA source breaks, data looks wrong, a model gets worse, a key expires: alert, then automatic fallback to the last good version

Safety rules

  • People approve every post, price change and message before it goes out. Agents draft; they never publish alone.
  • Agents can only read. They use the read-only database login, and the content rules (German law, no religious ritual words, no fake claims) are checked automatically.
  • Every model version is kept with its scores and the exact data it learned from, so any change can be undone in one step.
  • Private data stays private: customer and reviewer identities are hashed, and your own data is only visible to your business.
